# Satellite Data Analytics

## 📌 Project Overview

This project focuses on analyzing global satellite data to uncover meaningful trends, patterns, and insights across satellite records.

The analysis uses PostgreSQL and SQL for data exploration and analysis, with Power BI used to develop an interactive dashboard for data visualization and insight generation.

## 🎯 Project Objectives

- Analyze the distribution and characteristics of satellites across the available dataset.
- Explore satellite launch trends over time.
- Examine satellite records across different countries and operators.
- Identify important patterns and trends within the satellite data.
- Develop an interactive Power BI dashboard to communicate key findings effectively.

## 🛠️ Tools & Technologies

- **PostgreSQL** — Data storage and SQL-based analysis
- **SQL** — Data exploration, filtering, aggregation, and analysis
- **Power BI** — Interactive data visualization and dashboard development
- **Excel** — Initial data inspection and preparation

## 📊 Analysis

The project involves data cleaning, exploratory analysis, SQL-based calculations, and visualization of satellite-related information.

Key areas of analysis include:

- Satellite launch trends
- Satellite distribution
- Country-wise analysis
- Operator-wise analysis
- Satellite-related KPIs
- Trends across different years

## 📈 Power BI Dashboard

An interactive Power BI dashboard presents the major findings from the analysis.

The dashboard includes relevant KPIs, charts, filters, and visualizations to make the satellite data easier to explore and interpret.

## 💡 Key Insights

Key insights from the analysis will be presented through the Power BI dashboard.
